# Contact Card and User Management System

## Project Description

This project is a React application developed as part of my Web II Lab practice.

The project includes contact cards that display user information such as name, email, phone number, and profile picture.

It also includes a user management system with login, registration, logout, update, and delete features.

## Features

- Contact Card Component
- User Login
- User Registration
- User Logout
- User Management
- Update User Information
- Delete Users
- Responsive Design
- Unique Contact Card Feature
